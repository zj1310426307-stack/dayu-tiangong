# GIS 下一阶段计划

GIS-RESET-01 结束后按下列顺序推进，避免重新形成多底座。

## P0：生产化闭环

- 在授权维护窗迁移持久数据库并轮换角色口令。
- 为外部访问配置 TLS、证书校验、密钥托管和网络边界。
- 接入统一 IAM，把 actor/reviewer/publisher 与真实用户身份绑定。
- 建立数据库、GeoServer data dir、审计表的备份和恢复演练。
- 增加 OpenLayers、Catalog、WMS、FeatureInfo 的端到端监控与告警。

## P1：专业制图和数据质量

- 建立 QGIS QML 与 GeoServer SLD 的受控发布流程和视觉回归。
- 增加断面、闸泵与河网拓扑的领域规则和问题定位图层。
- 完成历史 Dataset Version 全量内容哈希与发布审计盘点。
- 实现发布版本保留策略、历史版本重新发布和显式回滚流程。

## P2：模型耦合

- 将 GIS 发布就绪与模型率定就绪拆成可审计状态。
- 建立边界条件、模型参数和空间版本的兼容性矩阵。
- 用真实测量/工况数据率定和验证水动力模型。
- 只有在安全联锁、权限、仿真验证和人工批准完成后，才讨论 PLC/SCADA 接入。

## P3：按需求扩展

栅格、三维、矢量瓦片或协作门户只能在有明确业务量、性能证据和独立 ADR 后引入。新增能力必须继续以 PostGIS Dataset Version 和统一 Catalog 为身份源，不得在浏览器、QGIS 工程或新数据库复制第二份权威目录。
