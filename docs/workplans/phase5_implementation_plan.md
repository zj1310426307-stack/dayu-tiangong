# Phase 5 多目标调度优化实施计划

## 范围

交付 PSO、多目标评价、硬约束、Phase 4 候选仿真复用、Pareto 分层、人工推荐、任务追踪和优化页面；不接真实设备，不实现强化学习或 AI 自主调度。

## 实施顺序

1. 冻结版本化目标/算法配置与 Phase 4 水动力输入。
2. 实现 PSO、候选解码、约束、目标函数和 Pareto 核心。
3. 建立三张持久化表以及 Celery 优化 Worker。
4. 以独立 `simulation_task` 执行每个有效候选并读取结果指标。
5. 提供任务、候选、Pareto、推荐和确定性解释 API。
6. 从 OpenAPI 生成前端客户端，完成配置/监控/详情页面。
7. 运行算法、迁移、端到端、类型、构建和浏览器验收。
