# GIS 坐标与测量标准

## 权威空间 CRS

- 核心业务几何、QGIS 暂存几何和发布视图统一为 **CGCS2000 / EPSG:4490**。
- QGIS 工程 `qgis/projects/dayu_tiangong_ltr.qgs` 的项目 CRS 固定为 EPSG:4490。
- 导入批次必须同时记录 `source_crs` 与 `target_crs`；目标只能是 `EPSG:4490`。
- 坐标转换必须由 QGIS 或 GDAL/OGR 做真实重投影，禁止只改 CRS 标签。

EPSG:4490 是地理坐标系，单位是角度。数据库的几何 SRID=4490 不意味着平面距离单位是米。

## 米制工程计算

以下工作必须使用经项目批准、适合工程所在区域的 CGCS2000 米制投影坐标系：

- 测量放样和 CAD 对齐；
- 河道/堤线长度、横断面距离；
- 缓冲、面积、邻近距离和拓扑容差；
- 需要工程精度的空间偏移和几何修正。

项目当前没有为所有未来工程区硬编码一个通用投影 EPSG。生产批次应由测绘负责人根据工程所在带号/中央经线确定 CRS，并在 `metadata_json` 或测量交付说明中记录：源 CRS、转换管线、格网/七参数（若使用）、软件版本和责任人。没有可靠源 CRS 时必须停止晋级，不能猜测。

后端当前用 PostGIS geography 计算河道声明长度与测地长度偏差，作为 warning；水动力数值仍使用业务字段中的米制 `river.length`、`cross_section.station` 和断面高程，不直接使用经纬度差。

## 垂直基准

EPSG:4490 只定义平面地理坐标，不定义工程高程基准。横断面高程、闸底/堰顶高程、泵站扬程等字段必须随工程资料记录垂直基准、单位和测量日期。

GIS-OPT-1 暂未建立独立的 vertical datum 表，也没有自动完成 1985 国家高程基准、地方高程系或其他基准转换。基准不明或混用时应产生人工阻断，不得因为平面 SRID 正确而判定整套测量合格。

## 数据类型和精度

- 河道：`LINESTRINGZ` 目前未启用，核心/暂存为二维 `LINESTRING`；高程不从线 Z 值推断。
- 横断面、闸门、泵站：二维 `POINT`；领域高程保存在明确字段/JSON 中。
- 坐标小数位不等同于真实精度；不得通过增加显示小数位伪造测量精度。
- `source_payload` 可保留来源附加信息，但不能绕过明确字段和质检。

## QGIS 操作清单

1. 打开工程后确认右下角 CRS 为 EPSG:4490。
2. 导入图层时先检查来源 CRS，不使用“指定图层 CRS”代替重投影。
3. 米制处理先另存/临时重投影到批准的 CGCS2000 投影 CRS，再把结果转换回 EPSG:4490 写入暂存。
4. 检查几何类型、空几何、有效性、重复几何、自相交和端点捕捉。
5. 将测量时间、操作人、源哈希和转换链写入批次/来源字段。
6. 运行平台 validation；QGIS 本地测量和拓扑检查只是辅助。

## 当前边界

本标准不替代测绘专项技术设计、控制点成果或工程精度规范。当前数据为 DEMO；真实工程接入前必须由测绘/水利专业人员确认平面与垂直基准，并对水动力模型完成率定和专项验证。
