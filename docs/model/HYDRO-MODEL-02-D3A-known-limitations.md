# HYDRO-MODEL-02-D3A 已知限制

D3A 是受限科学验证能力，不是生产模型。所有调用必须同时满足 capability readiness 与失败关闭合同。

## 水力范围

- 仅单 Branch，不支持分汊、汇流、环网或一般一维河网；
- 仅全湿，不支持湿润/干涸、岸滩启闭或移动湿干边界；
- 仅正向严格亚临界，不支持倒流、跨临界、激波或溃坝；
- 仅缓变非同 tabulated Profiles，不支持急缩、跌坎、断面突变、桥涵或堰流局部损失；
- 仅有效单值 Manning 糙率，不代表完整复合断面分区糙率；
- 河床必须显式、可追溯且沿程严格下降，不从断面最低点推断。

## 结构与控制

- 公开 D3A-3 路径仅验证一个 completed-interface Gate 和一个 external Q-H/Q-η Pump；
- 不支持多闸多泵组合、内排泵、自由出流闸、复杂启闭规律、优化调度、MPC/GA、PLC 或 SCADA；
- synthetic 事件只验证数值因果和守恒，不等同真实设备控制验证。

## 数据与用途

- 没有真实断面、实测边界、运行记录或水位/流量观测率定；
- 没有工程参数不确定性、敏感性、数据同化或预报检验；
- 不宣称 HEC-RAS/MIKE11 等价，不可用于生产供水、防洪或调度决策；
- 本地执行时间不是性能 SLA，托管 PASS 也不代表生产容量与可用性。

下一阶段应先进行 D3B 真实小型单河闸泵工程验证，再决定是否扩展一般河网或开展第三方模型对照。
