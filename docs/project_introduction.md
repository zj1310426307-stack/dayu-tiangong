# 大禹·天工项目介绍

“大禹·天工”是面向河网智能调度与数字孪生水利场景的工程平台。长期目标是统一承载河道空间、设施、观测、模型和调度方案，各阶段按可验证能力逐层建设。

Phase 1 已完成 GIS 一张图；Phase 2 将四类空间资产升级为版本化专业水利数据库，并增加河网拓扑、Excel/CSV/GeoJSON 导入、自动质量校验、边界条件、模型参数、计算方案和 Phase 3 输入快照。

当前 `V1.0` 演示版本包含 3 条河道、20 个横断面、5 座闸门、3 座泵站、8 个拓扑节点、7 个计算河段和 1 个基准工况。全部记录明确标识为 `DEMO DATA`，只用于验证数据库、API、空间显示和模型输入链路，不映射真实工程。

Phase 2 不执行水动力求解，不接入实时遥测，也不下发闸泵调度命令。模型结果、优化调度和 AI 决策将在后续阶段通过现有版本与契约边界增量接入。
