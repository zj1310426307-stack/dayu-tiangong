# 下游水位—流量关系曲线

## 用途

Standard 1D 的 `downstream_water_level` 边界支持 `values.mode=rating_curve`。
操作员在模型数据页选择下游端点和同河段上游流量边界后，平台从
末端活动横断面生成 Q–H 曲线，并按流量序列插值出下游水位序列。

## 算法和数据来源

- 断面：与定向 Branch 下游端桩号重合的最末活动 Profile。
- 断面水力：复用横断面数据库的分区 Manning 输水能力积分。
- 摩阻坡降：默认由末两个断面的深泓高程差除以桩号差推导；不能得到正坡时
  必须人工输入。
- 关系式：`Q = K(H) * sqrt(Sf)`，其中 `K(H)` 为断面分区 Manning 输水能力。
- 全归槽：曲线计算时在首末 Station 派生可重建的竖直岸壁，不修改 Raw
  Station/Elevation、Marker 或已审批 Profile。
- 范围：曲线至少覆盖所引用流量的 110%；任务映射禁止 Q–H 超范围外推。

## 冻结与失效规则

关系曲线保存输入断面/Profile、摩阻坡降来源、所引用上游流量边界 ID
和该边界值的内容哈希。建模时重新校验：

- 流量来源未被同一计算方案引用时拒绝；
- 流量边界变更导致哈希失效时拒绝；
- 曲线 Q 不严格递增、H 下降或需要外推时拒绝。

最终任务快照只包含评价后的 H(t)，Solver Adapter 不直接依赖平台存储格式。

## 能力边界

自动曲线是基于 Manning 均匀流和断面推导坡降的未率定建模辅助。它不是实测水位—
流量率定成果，不能替代回水、潮位、闸坝控制或实测资料明显主导时的动力边界。
