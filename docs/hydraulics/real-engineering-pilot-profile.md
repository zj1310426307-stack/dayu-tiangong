# REAL-01 真实工程准入档案

状态：`EMPTY / DATA_REQUIRED`。这是五河两闸资料的受控录入档案，不是计算结果或调度授权。可执行字段、状态枚举、阻断规则和机器可读空白模板以 [pilot-data-readiness.md](pilot-data-readiness.md) 为准。

## 录入人必须提供

| 域 | 最低材料 | 关键核验 |
|---|---|---|
| 河网 | 中心线、节点/分汊关系、上游到下游方向、CRS | CGCS2000 投影带、中央子午线、轴映射、转换证据。 |
| 断面 | Branch/Chainage、Station/Elevation、测量日期、单位 | 高程基准、点序、剖面来源和糙率依据。 |
| 水闸 | 两闸设计/实测资料、位置、孔数/孔宽、底槛、控制规则 | 每个参数有来源和审核责任。 |
| 边界 | 上游 Q(t)、下游 H/H(t) 或可审查关系、时间基准 | 单位、起止时刻、时区/相对时间、来源文件。 |
| 观测 | H/Q 观测、质量码、断面/站点位置 | 率定集与独立验证集不得混用。 |
| 责任 | 数据权属、资料负责人、审核人、用途 | 每个缺口有责任人和计划。 |

若做 MIKE11 对照，还必须提供可审计的合法导出输入/结果及版本说明；截图或手工转录不能替代可复算文件。

## 进入顺序

1. 导入预览，完成 CRS/垂直基准、完整性与来源 QA；
2. 全部 blocker 消除后冻结可运行图谱，先以 MASCARET 建立基线；
3. 用校准事件率定，用独立事件验收；
4. Gate/Pump 真实试点仅在建筑物和控制资料完整后，作为后续独立任务以明确 `pilot` 标签运行；
5. 一次试点不会自动获得生产资格，D-Flow 也不会自动升格。

## 禁止项

- 不得把峰值流量表当成 Q(t)；
- 不得将未知高程基准、未确认 CRS 或默认糙率标记为真实资料；
- 不得将一条河道样例扩展为五河两闸；
- 不得在 REAL-01 运行 D-Flow、生产计算或优化调度。

提交后先查看 REAL-01 readiness。只有所有 blocker 消除并已有通过的统一水力 QA 后，才可冻结 Dataset Version；冻结后仍需独立任务才能创建计算案例。
