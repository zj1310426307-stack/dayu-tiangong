# 真实工程试点资料画像

状态：`DATA_REQUIRED`。本文是资料清单和验收门槛，不把合成 Gate/Pump 验收表述为真实工程验证。

## 最小资料包

| 类别 | 必需内容 | 质量与来源要求 |
|---|---|---|
| 模型身份 | 工程、河段、版本、责任人、用途与许可 | 可追溯项目编号和交付授权 |
| 空间/高程基准 | CGCS2000 平面 CRS、中央经线、1985 高程或明确转换 | 书面基准说明、单位和转换责任方 |
| 河网与断面 | 上下游方向中心线、chainage、横断面 Station/Elevation、Marker | 完整覆盖计算河段，缺失/推断值明确标记 |
| 糙率与建筑物 | 分区糙率来源；Gate/Pump 几何、系数、能力曲线、初始状态 | 参数来源、测量日期和复核人齐全 |
| 边界与观测 | 至少一个校准事件和独立验证事件的 Q/H 时序与质量码 | 时区、采样频率、基准、断档和仪器信息完整 |
| 对照成果 | 若做 MIKE11 对照，必须是合法导出的输入/结果及版本说明 | 禁止截图或手工转录替代可审计文件 |

## 进入顺序

1. 导入预览、CRS/垂直基准和完整性 QA；
2. 冻结可运行图谱，先以 MASCARET 完成基线；
3. 用校准事件率定、用独立事件验收；
4. Gate/Pump 真实试点仅在结构与控制资料完整后，以明确 `pilot` 标签运行；
5. 达到专业审核标准后才能讨论生产资格，D-Flow 不会因一次试点自动升格。

## 明确不接受

没有上下游边界、没有观测时间基准、没有建筑物参数来源、将截图当作原始数据、或仅有合成数值测试的资料包，均不能进入真实工程验收。
