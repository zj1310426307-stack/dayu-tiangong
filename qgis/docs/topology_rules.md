# QGIS 编辑与拓扑规则

## 通用规则

- 所有几何非空、有效、类型与图层定义一致，SRID 为 4490。
- 编辑前选择平台创建的正确批次；禁止把不同 `entity_type` 混入同一批次。
- 捕捉仅作用于四个暂存层；参考层与发布层永远只读。
- QGIS 检查用于编辑反馈，平台 validation run 是可审计的权威门禁。

## 河道

- 折线应简单、无意外自相交、无重复节点或零长度段。
- 需要连通的端点应捕捉到同一位置；是否属于同一水力网络由平台拓扑检查确认。
- `code`、`name`、`length`、`level` 与 `status` 必填，`length` 必须大于零。

## 横断面、闸门与泵站

- 点位应捕捉到目标河道位置，`river_code` 必填。
- 每批次只包含一种对象，因此子对象不会在 QGIS 内硬关联到同批暂存河道。
- `operation` 必须选择 `upsert`（新增或更新）或 `delete`（删除）。
- `source_crs`、`source_hash` 与 `operator` 在 QGIS 中只读；保存新增记录时由数据库
  批次溯源触发器依据 `batch_id` 回填，不能把编辑端输入作为来源事实。
- `survey_time` 表示要素实际测量时间，允许编辑人员依据测量资料补充或修正。
- 横断面桩号非负、糙率大于零；闸门宽高大于零；泵站设计流量、扬程和功率非负。
- JSON 曲线与断面点序列的完整语义由平台复用既有业务校验器检查。

## 米制计算

EPSG:4490 为地理坐标系。长度、面积、缓冲和工程定位必须临时投影到项目批准的
CGCS2000 米制坐标系，并在批次元数据中记录转换链；不得把角度直接解释为米。
