# HYDRO-DATA-02｜公开脱敏验证模板

本目录只保存可公开复用的目录结构、字段契约和验收状态。真实工程名称、企业名称、
文件名、相对路径、文件大小、SHA-256、精确空间范围、坐标选择阈值、桩号区间和
断面映射均属于受控证据，只保留在本地归档，未发布到公开仓库。DWG、PDF、SHP 等
原始工程资料同样禁止复制或提交。

运行真实验证时，操作者需要在受控环境中提供私有叠加层，并把
`HYDRO_VALIDATION_CASE_ROOT` 指向案例资料根目录。工具必须在读取前核验私有清单中的
文件存在性和完整性；环境变量未设置、私有配置不完整或摘要不一致时应立即停止。

目录约定：

- `metadata/`：公开脱敏模板；真实案例使用未发布的私有叠加层补全；
- `raw/`：仅供运行时受控挂载或链接，内容全部忽略；
- `staging/`：标准化中间结果，内容全部忽略；
- `expected/`：只允许无敏感信息的通用基准；
- `outputs/`：本地验收产物，内容全部忽略。

受控本地环境已完成真实数据导入、断面质量检查、查算与数据库迁移演练；详细源清单、
空间明细、逐断面映射和完整性摘要没有公开。可公开的科学结论如下：

- 各已接纳河段内部桩号连续，断面几何 QA 通过；
- 实际网络形成 **3 个不连通分量**，不满足含汇流节点的生产验收要求；
- 缺少权威控制点、已核定水力方向、建筑物参数和当前片段上下游边界；
- 真实案例 v3 快照、求解器、OpenLayers 数据闭环和风险范围均未验收。

因此生产总体结论仍为 **NO-GO**。公开模板不能替代受控证据，也不能被解释为真实
工程数据已经发布或生产能力已经通过。
