# D3A-1 positive-Manning Gate/Pump benchmark

This validation-only synthetic case derives from the frozen D1 six-hour case.
It changes only the explicit capability/provenance identity and every
section/cell effective Manning coefficient from `0.0` to `0.025`.

The scope remains one Branch, fully wet, flat bed, identical Profiles,
forward strictly subcritical flow, one completed-interface Gate and one
external hydraulic Q-H/Q-efficiency Pump. It is not a calibrated or
production-decision model.
